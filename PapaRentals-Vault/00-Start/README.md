# How to open this in Obsidian

This folder **is** an Obsidian vault. Two ways to use it:

**As its own vault**
1. Copy `PapaRentals-Vault/` anywhere on your machine.
2. Obsidian → *Open folder as vault* → pick that folder.

**Inside an existing vault**
1. Copy `PapaRentals-Vault/` into your vault folder as a subfolder.
2. Obsidian picks it up on next launch. Links are all relative wikilinks, so
   they resolve either way.

No plugins are required. Graph view, backlinks and tag search all work out of
the box. If you use the Dataview plugin the frontmatter (`tags`, `updated`,
`area`) is already there to query against.
